BLUE BIRD HOME SERVICES — WEBSITE

OPEN: Double-click index.html to preview the website in a browser.

PUBLISH FREE:
1. Create a free Cloudflare account.
2. Open Workers & Pages > Create > Pages > Upload assets (Cloudflare's UI may change).
3. Upload the contents of this folder, or zip it and upload if supported.
4. Cloudflare will provide a free *.pages.dev website address.
5. Optionally buy bluebirdhomeservices.com if available and connect it as a custom domain.
